# HireMeMaybe V2 - Premium AI Career Platform

A sophisticated AI-powered career coaching platform that uses Google Gemini and IBM Watson to analyze resumes and provide real-time audio coaching.

## 🚀 How to Run Locally

This project requires **Node.js** installed on your machine.

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Setup Environment Variables:**
   Create a `.env` file in the root directory and add your API keys:
   ```env
   GEMINI_API_KEY=your_gemini_key
   IBM_WATSON_API_KEY=your_watson_key
   IBM_WATSON_URL=your_watson_url
   ```

3. **Start the Server:**
   ```bash
   npm start
   ```

4. **Open in Browser:**
   Go to `http://localhost:3000`

## ⚠️ Important Note on Deployment
This is a **Node.js Fullstack App**. It will **not** work on GitHub Pages. To host this online, use a platform like **Vercel**, **Render**, or **Heroku**.
